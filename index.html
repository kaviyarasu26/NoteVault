Cross-Device Workflow
1
Laptop: Open NoteVault.html in Chrome. Write flashcards using Question >> Answer
2
Laptop: Go to Sync → Export All. Save the .nvault file to Google Drive / send via WhatsApp / email.
3
Phone: Download the file. Open NoteVault, go to Sync → Import. Choose Merge to keep review progress.
4
Phone: Tap ▶ Review on home screen for your daily recall session.
5
Phone: After reviewing, Export again. The .nvault file now has your updated schedule. Import back on laptop to keep in sync.
