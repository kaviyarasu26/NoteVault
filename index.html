Keyboard Shortcuts
⌨️
Ctrl/Cmd + S: Instantly sync your data to the cloud.
⌨️
Ctrl + Space: (Or Alt + /) Instantly inserts the >> flashcard separator while typing.
⌨️
Alt + H: Highlight & bold the selected text in yellow (shown in Review & Search).
⌨️
Alt + Enter: Insert a line break within the same item (e.g. stacked terminal commands).
⌨️
Backspace at the start of an empty item deletes it and merges back to the previous one.
⌨️
Spacebar: Reveal the answer during a review session.
⌨️
1, 2, 3, 4, 5: Rate your memory recall quickly.
Search Syntax
🔍
word — content contains word (default)
🔍
a+b — exact phrase "a b"
🔍
A AND B — both present anywhere
🔍
A OR B — either present
🔍
A NOT B — A present, B absent
🔍
f:text — title-only match
🔍
d:text — folder-name-only match
🔍
*text* / a?b — glob wildcard, matched against title + content
🔍
bare multi-word (e.g. apple pie) — implicit AND between terms
